# La Liga Crest Symbols Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give La Liga's 20 clubs curated *futebol de botão* discs, so they stop rendering as two-letter initials on both apps.

**Architecture:** Pure data. Twenty entries are added to one Swift source of truth, copied to a second Swift repo by an existing hash-stamping script, and ported to a third Kotlin copy. No enum case is added and no renderer is edited — but six entries are the first ever to use `concentric`, a path that has only been dead code, so the plan ends by looking at it on both platforms.

**Tech Stack:** Swift / Swift Testing / Xcode; Kotlin / JUnit 4 / Gradle; `sh` for the sync script.

Spec: `footballWhiteLabel/docs/superpowers/specs/2026-08-07-la-liga-crest-symbols-design.md`

Three repositories are involved. This plan lives in `footballWhiteLabel`, which is the source of truth.

## Global Constraints

- **`footballWhiteLabel/BR2026/Models/TeamCrestSymbol.swift` is the source of truth.** Never hand-edit the `worldcup` copy — it is produced by `scripts/sync-crests.sh`, and both copies carry a hash stamp of their own content that `CrestSyncTests` verifies in each repo. Editing the copy directly makes that repo's tests fail, which is the mechanism working.
- **Never retype a hex or a weight into the Kotlin file.** `CuratedCrestSymbols.kt`'s own header says a mistyped digit is a wrong club colour that no test would catch. Task 3 supplies a transform to run rather than a table to copy.
- **The 20 entries, hexes and weights are fixed.** They were approved on the crest board at 20 px. Do not "tidy" a colour, round a weight, or reorder a band list — the differences between several of these discs are deliberate and small. Use the spec's values verbatim.
- **Neither Swift repo uses Conventional Commits**; both use a sentence-case imperative subject with no prefix. Same for the Android repo. End every commit message with:
  `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`
- **Do not push any repository.** Vinicius decides when these ship; both apps go through store review.
- **All three repositories have dirty working trees, and none of it is yours.** `footballWhiteLabel` carries ~45 untracked screenshots, design assets and fastlane metadata plus one modified doc; `worldcup` has a couple; `WorldCupAndroid` has ~18 (`.DS_Store`, `fastlane/README.md`, deleted files under `prints/`, untracked `android-export/` and `res/`). **Stage only the exact paths each step names. Never `git add -A`, `git add .`, or `git commit -a`.** Run `git status --short` before each commit and confirm you are staging only your own files. The crest files themselves are clean in every repo, so nothing you need is caught up in this.
- **Do not add a committed Android port script.** The spec names it as the follow-up and puts it out of scope.

- [ ] **Step 3: Generate the Kotlin entries from the Swift source**

**Do not retype the hexes.** Run this transform, which reads the Swift file you just committed and emits the Kotlin block:

```bash
python3 - <<'PY' > /tmp/laliga-kotlin.txt
import re
SRC = "/Users/mlbbr-mac-vinicius/projects/footballWhiteLabel/BR2026/Models/TeamCrestSymbol.swift"
IDS = [544,535,548,542,540,530,531,529,539,543,4665,541,536,797,532,728,533,538,546,727]
text = open(SRC).read()
# Each entry starts at "<indent><id>: ." and runs to the next entry or the dict close.
entries = dict(re.findall(r'^        (\d+): (\..*?)(?=^        \d+: \.|^    \])', text, re.S | re.M))
def w(x):
    x = x.strip()
    return x if x.endswith('f') else (x + 'f')
for tid in IDS:
    body = entries[str(tid)].strip().rstrip(',')
    if body.startswith('.equalStripes(['):
        hexes = re.findall(r'"([0-9A-Fa-f]{6})"', body)
        print(f'        {tid} to equalStripes({", ".join(chr(34)+h+chr(34) for h in hexes)}),')
    elif body.startswith('.verticalStripes(['):
        bands = re.findall(r'\.init\("([0-9A-Fa-f]{6})",\s*([0-9.]+)\)', body)
        inner = ", ".join(f'Band("{h}", {w(v)})' for h, v in bands)
        print(f'        {tid} to VerticalStripes(\n            listOf({inner})\n        ),')
    elif body.startswith('.concentric(['):
        bands = re.findall(r'\.init\("([0-9A-Fa-f]{6})",\s*([0-9.]+)\)', body)
        inner = ", ".join(f'Band("{h}", {w(v)})' for h, v in bands)
        print(f'        {tid} to Concentric(\n            listOf({inner})\n        ),')
    elif body.startswith('.diagonalSash('):
        bg, st, wf = re.search(r'background:\s*"([0-9A-Fa-f]{6})",\s*stripe:\s*"([0-9A-Fa-f]{6})",\s*widthFraction:\s*([0-9.]+)', body).groups()
        print(f'        {tid} to DiagonalSash(background = "{bg}", stripe = "{st}", widthFraction = {w(wf)}),')
    else:
        raise SystemExit(f"unrecognised symbol for {tid}: {body[:60]}")
print(f"# generated {len(IDS)} entries", flush=True)
PY
cat /tmp/laliga-kotlin.txt```

Expected: 20 lines of Kotlin plus a `# generated 20 entries` trailer. If it raises
`unrecognised symbol` or prints fewer than 20, stop — the Swift file is not shaped the way

This transform has been run against a fixture of exactly these entries and produces valid
Kotlin. It never retypes a colour: every hex and weight is lifted out of the Swift source
by regex, which is the property the file's own header asks for.
